## How is a Player put together?
- User prompted for the players name
- User prompted to choose a gender for the player (He/She/Neutral) for pronoun purposes only
    - I don't think it is worth storing as an attribute but I don't know what else it could be stored as
- User given a list of all player races and prompted to pick one
    - When the user picks a race they are given more detail on the race they selected and given a confirmation choice (if no they got back to the initial list)
    - The more detail is essentially just the base stats of that class as well as the race skill and a line describing what it does
- User repeats this but for their class
    - Difference is that instead of being showed base stats they are shown the class' growth rates for each stat. Instead of a race skill, they are shown the name of their class's respective skill tree.
    - Additionally, depending on their class it will assign them a starting loadout (gear/items)based on 3 options.
- Player is given 10 stat points to spend to individualise their stats (before gears stats are applied)
- The player starts their skill tree with the node unlocked, which is like an initial boost for their player.
- Also to clarify, skill trees do not just contain skills, they can have passive/active skills, stat increses, other boosts (addition belt slot, etc), not all of which is combat related
- The User is then shown a full profile of the character they created, with stats (shown as: stat_name: stat_num (+gear_num)), skills, starting loadout. They are asked to confirm this if not the process repeats.
